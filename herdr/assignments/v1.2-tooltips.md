## Behaviour
- Only when `E.settings.on('itemTooltips')`. Hover (mousemove over the canvas, logical coords through `E.display.viewToLogical`) on a printed item name in an item list -> a tooltip panel (game/engine/ui.js `drawPanel`, scale 1, the shared style) near the pointer with the stats the owner lists: weapons damage / hits / ammo / reloads / range / weight / price; armor absorption / weight / price; ships hull / cargo / fuel / weapon slots / price; crew candidates class / skills / wage. Gamepad: the item under the v1.1 gamepad highlight (`E.input.highlight`, {key,row,col,len}) gets the tooltip too.
- Item recognition: match screen text rows (`E.text.screenText()`) against the item names from items.json for the current module/screen (exact name as printed, including truncation the screen applies; document per screen); a name may appear in several groups: disambiguate by the screen (e.g. PT-04 Buy lists squad weapons). Where a list row shows a selector (`1>`, `A-`), the tooltip belongs to that row.
- Tooltip text must say only what the decode supports; each value's source is in items.json (not printed).
- Expose `E.tooltips = { at(lx, ly) -> {title, lines} | null }` for tests and v1.3.
