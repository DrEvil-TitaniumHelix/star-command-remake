Steps (commit after each with a pathspec; the index is shared):
1. **Manifest** `docs/byoc/manifest.json`: for the known release, every file name, size and SHA-256 (hashes only, no content), which files are required (the 7 module EXEs, BRUN30.EXE, every file the game BLOADs/OPENs per `game/assets/files/` + DATA_FILES.md) and which optional (COLOR/DEMO/FIXIT). A node script `tools/byoc/make_manifest.mjs` regenerates it from a folder.
2. **Importer page** (`game/byoc/import/`): shown when OPFS has no converted assets; `showDirectoryPicker()` (read-only), fallbacks `<input webkitdirectory>` and a .zip drop; validates against the manifest (clear message naming the missing/mismatching file and the expected size); progress bar; runs conversion in a Web Worker; writes to OPFS `sc-assets/<manifest-version>/` with a `done` marker and the recipe version; re-converts when the recipe version changes; never touches save games.
3. **Tier 1 in JS** (`game/byoc/convert/`): ports of convert_data.py (byte copies + data JSON), items.py, gmap stays our own file. Output byte-identical to today's `game/assets/files/*` and `game/assets/data/*.json` (manual.json excluded: the manual is not in the game folder; the Manual feature falls back to our own "what the game really does" notes, per docs/BYOC.md 3.2).
4. **Tier 2 in JS**: port of build_atlas.py + bsave.py; `atlas.png` + `atlas.json` byte-identical (or pixel-identical PNG with identical JSON if PNG encoder bytes differ; say which).
5. **Engine switch:** one `assetsBase` setting so files.js / data.js / sprites.js read from OPFS (service worker or object URLs); default stays `game/assets/` until B6 removes the originals, so today's game keeps working.
6. **Veteran save as a recipe:** run make_veteran_save's logic in the worker against the converted INFO.json, output byte-identical to `game/assets/saves/veteran/CHARINFO.BAS`.
7. **Tests:** `game/byoc/assets.test.mjs` in node: convert from the originals on this machine and assert equality with the committed assets (skip with a message when the originals are absent). Browser check of the importer only when the single headless-Chrome slot is free (check `tasklist | findstr /i chrome` + headless command lines first; stop yours after).

Run `bash tools/check_js.sh` and `node game/engine/*.test.mjs` before committing under `game/`. Never modify the originals. Shell rule: rm paths as `"${VAR:?}/..."` or literals. 5-line STATUS.md block per step with `date` output; DONE block at the end.
