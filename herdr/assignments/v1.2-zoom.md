## Behaviour
- Only when `E.settings.on('mapZoom')` and only on map screens (a map provider is active for the current screen: derive it from `E.pointer.regions()` containing kind 'map', or the module + provider area; document). Elsewhere the view stays 1 and wheel/clicks behave as v1.1.
- Wheel over the canvas: zoom in/out around the pointer (keep the logical point under the pointer fixed), steps 1, 1.5, 2, 3, 4 (nearest-neighbour; integer steps keep the pixel grid exact - say which steps you keep), clamp so the view stays inside the 320x200 picture (setView clamps). preventDefault so the page does not scroll.
- RMB click = zoom out one step (contextmenu suppressed on the canvas). LMB click: v1.1 hotkey/cell click wins (pointer.js handles it); zoom-in on LMB only where LMB has no v1.1 meaning: per screen decide (table in the report): on maps LMB = step the cursor (v1.1), so zoom-in = wheel or double-click; everywhere else no zoom.
- The view resets to 1 when the screen changes away from a map (SCREEN/CLS, module CHAIN, the map provider disappearing) and on Esc overlay open (`E.input.modal`), so overlays, text and acceptance shots are never zoomed by accident. Pan: when zoomed, the view follows the map cursor if it would leave the visible area (optional; document).
- Expose `E.zoom = { level, reset, zoomAt(lx, ly, step) }`.
