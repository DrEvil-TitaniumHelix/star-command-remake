# v1.3 settings — lane v13-settings

Implemented Part settings; no commits.

## Design

Esc retains R-Resume, S-Save & Quit, Q-Quit without saving and adds T-Settings as the fourth item. The Settings page lists Classic mode then every FEATURES entry. Arrows select, Enter/Space toggle, the displayed unique letters toggle directly, Esc/B return to the Esc menu; clicks use the same rows. Classic greys every feature and displays OFF while retaining individual preferences. Forced Classic (`?classic=1`) displays `(forced)` and cannot be changed. Settings stay available in Classic.

Settings persist immediately under `starcommand:settings`; storage reads, writes, JSON parsing, and access to the localStorage getter are guarded. The settings object remains usable without storage.

The overlay installs a live `E.options.protection` getter backed by `!E.settings.on('noChallenge')`, so changing the switch immediately selects STARPORT's existing original challenge branch (flow.js 09BE9) without module edits. An explicit initial protection=true sets noChallenge=false; assignments used by acceptance screen setup also update the switch. Classic always takes the challenge.

Minimal marked pointer.js guards suppress regions, clicks, and hover while mouse is disabled, including modal clicks. Re-enable via keyboard. Modal clicks use unzoomed picture coordinates so Settings remains accurate after opening Esc from a zoomed map.

Rendering uses ui.js drawPanel, in display.overlays only. The underlying game remains paused through Settings and Back; returning to the game releases the existing pause gate.

## Settings keys and labels

Existing: mouse — Mouse control; noChallenge — Skip rule-book question; controlOverlay — Control overlay (F1); mapZoom — Map zoom; itemTooltips — Item tooltips.

Added to FEATURES: enemyTooltips — Enemy tooltips; rangeOverlay — Range overlay; hitPreview — Hit-chance preview; crewPanel — Crew status panel; logBook — Log book; saveSlots — Named save slots; manual — Manual on demand; speed — Speed toggle; missionMarker — Mission-target marker.

Classic is the master setting (`classic`), outside FEATURES. Direct shortcuts are generated in list order using A,C,D,E,F,G,H,I,J,K,L,M,N,O,P; B stays Back. All nine new features are registered here for coordinator integration, while their implementations remain with their assigned lanes.

## README text to merge

**v1.3 Settings.** Esc → T opens the Settings page. Use arrows plus Enter/Space, the displayed letters, or mouse clicks to toggle each addition; Esc/B returns. Preferences apply immediately and persist locally when browser storage is available. Classic mode disables every addition while keeping individual preferences for later. `?classic=1` forces Classic for the session. Disabling Mouse control also disables modal clicks; use the keyboard to enable it again. Disabling Skip rule-book question restores the original STARPORT challenge, as does Classic mode. Settings and the Esc menu draw above the picture and pause game time without changing game pixels.
