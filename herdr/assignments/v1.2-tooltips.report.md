# v12-tips report

Lane: v12-tips. No commit. Changes are confined to the assigned generator, generated items.json, tooltip implementation, tooltip tests, this report, and the requested acceptance screenshot output directory. Other lanes' existing changes were left alone.

## Delivered

- `python -I tools/items.py` generates 152 records from INFO.json and NAME.json with raw fields and a decode citation for every field. Python 3.13.15 was used. No originals are read or modified.
- `installTooltips(E, canvas)` installs `E.tooltips.at(logicalX, logicalY)`, plus `ready` for asynchronous loading and `error` for load diagnostics. Disabled settings return null and draw nothing.
- Pointer coordinates pass through `E.display.viewToLogical`. Panels use `ui.js` drawPanel at scale 1. No framebuffer writes, key injection, or module changes.
- Gamepad focus uses the existing one-based highlight rectangle and current screen text. Mouse leave clears pointer tooltips. Ambiguous matches return null rather than selecting an arbitrary record.
- Crew selector rows expose class, skills, and monthly wage from live crew fields and the generated rank-pay records.

NAME group starts: ships 29, shields 42, defense 47, missile killers 52, guns 55, squad weapons 80, hand weapons 134, sighting 140, armor 144, misc 160. STARPORT 0239-0586 reads these groups; DATA_FILES.md explains NAME and the INFO column-major layout. Training and cargo-value records are outside the assigned item groups.

Purchase prices retain both the raw INFO price and the single-precision price * 1.2 actually charged (STARPORT 076F-077B, 0791 and each purchase statement). Ships additionally retain the displayed integer price (05227: PRINT INT(Price!)). Purchase lists show purchase price; other supported contexts show explicitly labelled base price. No sale quote is inferred from base price.

Weight columns remain the original INFO values. Purchase routines multiply these by 10 when storing tenths in G; the corresponding display divisions undo that conversion. These are not divided by 10 a second time. Unknown columns remain in JSON for traceability and are omitted from tooltip text.

Crew numbers: STARPORT G-layout and 646D-6608 use record base 1300+100*m; field 34 rank, 35 class, 17..28 skills. Class names are 01C4-01DF; skill labels come from Skill$(1..12). Monthly wage uses the corresponding PayTable record, not the accumulated mission-pay amount. PLBATTLE 05331-05395 supports the clamped loaded-ammo/reload digits printed on a named weapon row; those appear as explicitly labelled shown values when available.
