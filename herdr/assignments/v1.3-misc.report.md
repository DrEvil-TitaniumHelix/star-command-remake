# v1.3 misc — lane v13-misc

Implemented in owned files only; no commits. Other lanes' shared workspace changes were left alone.

## Design

- `manual.js`: independent Manual button, screen index selector, previous/next page and close buttons. No game key consumed. Canvas text uses shared drawPanel, never framebuffer writes. All screen ids in SCREENS_INDEX have a title and chapter page mapping to the original OCR. Each screen's chapter discrepancies display “manual says …; the game does …” with decode evidence. Full OCR remains verbatim in manual.json; no invented rules.
- `tools/manual_pages.py`: deterministic extraction from the checked-in OCR, SCREENS_INDEX and MANUAL_XCHECK; generates `game/assets/data/manual.json`.
- `speed.js`: F2 and button cycle normal / fast / fastest (1x / 4x / 16x). Wraps timer.delaySeconds, so timer.delayLoop continues through the Esc overlay's existing wait/pause policy. Does not touch G!(86), G!(88), TIMER, frame polling, fixed waits, audio, or RND. Setting off immediately restores the original delay computation. F2 uses the engine device-hotkey seam, after modal routing and before the game queue.
- `marker.js`: yellow overlay boxes around unfinished mission target sectors. Reads active flags G!(110..159) and live mission codes/coordinate pairs. Completed flags and cleared target codes suppress markers. Galaxy overview and visible long-range tile use the decoded projection; other views and prose covering the picture suppress drawing. Tracks scan title sprites and resets on CLS. Applies the current zoom transform. Does not depend on mouse being enabled.
