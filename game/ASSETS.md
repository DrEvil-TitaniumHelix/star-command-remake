## Atlas format (data-driven sprites, owner/coordinator 2026-10-15)
- `atlas.json`: `{scale, palette[16], width, height, sprites: [{bank, index, x, y, w, h, mode}]}`. `bank` = file name as in sprites_index.tsv (`TITLE.BAS`, `BIGSH-1.EGA`); `index` = that tsv's array number, so SCREENS_INDEX.md `BANK[i]` maps 1:1. `w`/`h` are logical pixels; in the PNG a sprite covers `w*scale` x `h*scale` pixels at `(x*scale, y*scale)`.
- Pixel values are colour **numbers** (attributes), not colours: `cga` sprites hold SCREEN 1 attributes 0..3 (displayed through the module's PALETTE, e.g. 1 -> EGA 9, 2 -> EGA 4), `ega` sprites hold 0..15. The PNG's palette is the 16 EGA colours, so a CGA sprite previews in black/blue/green/cyan; the loader maps RGB back to the number via `atlas.json.palette`.
- Swapping art later (deferred art pass): write a new `atlas.png` + `atlas.json` with the same `bank`/`index` keys and e.g. `scale: 4`; the framebuffer runs at `320*scale x 200*scale` and no code changes. Pixels must still be colour numbers through `palette`.

## Notes
- **CGA-only banks.** Every SCREEN 1 module (STARTUP, SPACE, STARPORT, INSIDE, SPBATTLE) loads `.BAS` banks only, also on an EGA; the `.EGA` banks (BIGSH-n, LOGO, PLBTSH, TR-n) are PLBATTLE's SCREEN 7 art. So the "CGA-only sprites" of BUILD_PLAN §7 are all banks except those 16, and they are shown exactly as the original shows them on an EGA: attributes 0..3 through the module's PALETTE remap (display.js `MODULE_PALETTE`).
- There is no `SHIP-1.EGA` in the shipped files (assignment text); the demo uses `SHIP-1.BAS[0]` for SCREEN 1 and `TR-1.EGA[0]` / `BIGSH-1.EGA[0]` for SCREEN 7.
- `DEMOSH.BAS` (DEMO.EXE only) and `GAL.BAS` (no module literal) are in the atlas for completeness; no module uses them.
- **Serving.** Chrome refuses ES modules and `fetch()` from `file://`, so the game must be served over HTTP: `python -I tools/serve.py` -> http://localhost:8088/ (any static host works, e.g. GitHub Pages). A file:// build would need a single-file bundle step (not done; Foreman decision if wanted).
