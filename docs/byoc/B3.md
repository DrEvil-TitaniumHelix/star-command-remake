Result (node v24, this machine, originals present): all 7 listings, all 7 `_<MOD>.json` tables (deep-equal), all 5
`.bas.md` and all 7 generated JS files byte-identical; about 0.1-0.25 s per module.

8086 decoder. Inventory of the 7 listings (Fable scratch `opinv.txt`, re-derived): 46,317 decoded instructions, 65 opcode
keys, 33 mnemonics, no prefixes, 4 `db 0xff` (FF /7 = invalid, capstone returns nothing). The decoder implements the
whole one-byte map with the same tables, so data areas decoded as code (`00 00` = `add byte ptr [bx + si], al`, the 186
`c1 02 ff` = `rol word ptr [bp + si], 0xff`) come out as capstone prints them. Prefixes, the 0F escape and the rare 186
forms throw instead of guessing. Differential check against capstone 5.0.7 itself (random seeded encodings over all 256
opcodes, ModR/M shapes, load addresses, truncated buffers): 0 mismatches on 70,471 decodable cases out of 76,800; the
rest are the forms dis16 rejects on purpose (prefixes 26 2E 36 3E 64-67 F0 F2 F3, 0F, FPU D8-DF, the VEX/EVEX register
forms of C4/C5/62 that capstone decodes as AVX, TSX C6/C7 /7). Capstone quirks matched on the way: `cwde`/`cdq` for
98/99, `rcl <mem>` without `, 1`, 83-group or/and/xor print the sign-extended imm8 unsigned (`0xffdd`), `enter` and the
F6 /1 test alias print signed, `lea` no size, `les`/`lds` `ptr`, `lcall seg, off` vs `ljmp seg:off`. One rule found by the
listing diff: branch targets are not wrapped to 16 bits
(`call 0x103e2` at SPACE 088DA, `call 0xffffa932` at STARPORT 01506 = next + rel as unsigned 32-bit); 51 such lines.
Other format rules: imm `0x%x` above 9 else decimal; 83-group imm8 signed (`-0x46`); displacements signed; direct
addresses unsigned; `xchg`/`test` print r/m first.

Port traps kept (each changes bytes if missed): Python dict displays in qb2bas evaluate every entry, and those calls bump
the usage counters that order the Variables table kinds (`Counter.most_common` ties = insertion order); JS objects
reorder digit-only keys (INSIDE `Surprise!` at 3B24 and at 9588 - the first in names order wins), so names are parsed into
a `Map`; `json.dumps` escapes everything above 0x7E; Python `\w`/`\s`/`strip()`/`splitlines()` are Unicode-wide.
