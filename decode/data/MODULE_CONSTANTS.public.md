# Star Command module constant areas (string literals, numeric constants, DATA, line tables)

**Public variant** (no game text: texts are given as load-module offset + length; the importer reads them from the player's EXEs). Full version: MODULE_CONSTANTS.md (RE workspace only).

Lane: data. Generated by `decode/data/tools/gen_constants.py` from `decode/data/tools/modconst.py --json` runs over the originals in `re-targets/starcommand/starcoma/` (read 2026-10-15). Regenerate: `python decode/data/tools/modconst.py <MOD>.EXE --json decode/data/tools/_<MOD>.json` then `python decode/data/tools/gen_constants.py`.

## Layout of a compiled QuickBASIC 3.00 module (evidence-backed)

All offsets below are **load-module offsets** (file offset minus the 0x200 MZ header; same numbering as `decode/listings/*.lst`). Addresses in the tables are **DS offsets** of the BRUN30 data segment: the module's constants are copied there at start-up, and the listings reference them as immediates (`mov bx, 0x4896`).
