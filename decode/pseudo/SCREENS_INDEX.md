# SCREENS_INDEX — master screen inventory (lane screens-index, Opus, 2026-10-15)

Input for `BUILD_PLAN.md`: one row per distinct screen the player can see, in module order STARCOMM → STARTUP → SPACE → STARPORT → INSIDE → SPBATTLE → PLBATTLE (+ the floppy stubs).

Every row is built from the module lane's `<MOD>_SCREENS.md` and checked against other sources:
- **Strings:** the verify lane proved every quoted string in those files byte-equal to the module's string table (`<MOD>_VERIFY.md` → Names/screens pass).
- **Sprites:** names are resolved to bank file + array index by mapping each array's DS address through the module's `BLOAD` base onto `decode/data/sprites_index.tsv` (script in the verify scratchpad; the results are in the sprite tables below).
- **Keys:** checked against the module's `ON Cmd! GOTO` dispatch tables (see Consistency).
- **CHAIN edges:** from `CROSSREF.md` §1.

PLBATTLE rows added 2026-10-15 after PLBATTLE_VERIFY.md (237/237 AGREE).

## Conventions

- **Id:** CM = STARCOMM, SU = STARTUP, SP = SPACE, PT = STARPORT, IN = INSIDE, SB = SPBATTLE, PB = PLBATTLE, ST = .STR stub. Sub-screens use letters (SP-04a).
- **Mode:** every module runs in **SCREEN 1** (320x200, 4 colours, text 40x25, 8x8 cells: column c at x = 8(c-1), row r at y = 8(r-1)). The only exception is PLBATTLE, which uses SCREEN 7 (320x200, 16 colours) when an EGA is present.
- **Palette per module:**

  | module | CGA (UseEGA! = 0) | EGA (UseEGA! = G!(89) = 1) |
  |---|---|---|
  | STARCOMM / STARTUP | `COLOR 0,1` (palette 1: black, cyan, magenta, white) | `PALETTE 1,9: PALETTE 2,4` (STARTUP toggles to `PALETTE 1,3: PALETTE 2,5` when CGA is chosen) |
  | SPACE, STARPORT | as above | `PALETTE 1,9 / 2,4` |
  | **INSIDE** | as above | **`PALETTE 1,2: PALETTE 2,6`** (bytes 0E08-0E13) |
  | SPBATTLE | inherits SPACE's | inherits SPACE's |

- **Text** is given as `row,col "literal"`; `;` means no newline. Strings are verbatim, including spaces and the original spellings.
- **Sprites** are `BANK[i]` = array i of that bank in `sprites_index.tsv`; `-n` banks are numbered families (`SHIP-n.BAS` = SHIP-(class+1)). PUT verbs: OR / AND / PRESET / PSET / XOR. `GET` buffers (screen captures) are marked `(GET buf)`.
- **Keys:** `A-..` = letter menus (either case); arrows = Up/Down/Left/Right; ENTER, SPACE, BACKSPACE, ESC as named. `Press ENTER Key` / `Press SPACEBAR` = wait for that key.
- **Transitions:** `→ id`; `⇒ MOD` = CHAIN to that module, landing at that module's entry screen (`.STR` targets pass through ST-01 on floppy configurations).
